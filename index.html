Events API

API Endpoint

GET https://405vzfe.github.io/events/events.json

Today's Events Status

Usage

Returns the market-event flags for the current UTC date, scheduled hourly from 00:17 to 12:17 UTC (best-effort; runs may be late or dropped). The file is a one-day snapshot: compare date against your own clock.

Response Format

{
  "date": "2026-10-02",
  "opex_minus_one": false,
  "vixpiration_minus_one": false,
  "vixpiration": false,
  "vixpiration_plus_one": false,
  "eoq_plus_one": false,
  "earlyClose": false,
  "fomc": false,
  "fomcPlusOne": false,
  "cpi": false,
  "eom": false,
  "eoq": false,
  "opex": false
}
